ℹ️ What does this calculator measure?

Position-Level Diversification: This calculator measures how your capital is spread across different positions (individual holdings). It treats each holding equally at the portfolio level.

What it SHOWS:

  • ✓ How many different investments you own
  • ✓ How concentrated your money is in top holdings
  • ✓ Portfolio composition by allocation %
  • ✓ Geographic exposure by exchange

What it DOESN'T capture:

  • ✗ Underlying diversification within ETFs (e.g., GLOBAL-ETF holds 3500 stocks vs US-STOCK is just 1)
  • ✗ Overlap between holdings (e.g., GLOBAL-ETF + US500-ETF are ~40% overlapped)
  • ✗ Currency exposure differences (SGD vs USD vs GBP)
  • ✗ Correlation between holdings
  • ✗ Industry sector concentration

Example: A portfolio with 50% US-STOCK + 50% GLOBAL-ETF shows the same position-level diversification as 50% US-STOCK + 50% any other single stock. But true diversification differs because GLOBAL-ETF itself contains thousands of stocks.
